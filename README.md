# Olimpo Tattoo Studio

## Project Overview
This project is a simple website for the Olimpo Tattoo Studio, featuring a responsive design with a navigation bar that includes a hamburger menu for mobile devices.

## Files Included
- **index.html**: The main HTML file that contains the structure of the webpage, including the navigation bar and hamburger menu.
- **style.css**: The stylesheet that defines the styles for the webpage, including the hamburger menu icon and responsive design rules.
- **script.js**: The JavaScript file that adds functionality to the hamburger menu, allowing users to toggle the visibility of navigation links on mobile devices.

## Setting Up the Project
1. **Clone the Repository**: 
   ```
   git clone <repository-url>
   ```
2. **Navigate to the Project Directory**:
   ```
   cd olimpo-tattoo
   ```
3. **Open the `index.html` File**: You can open this file in any web browser to view the website.

## Using the Hamburger Menu
- On mobile devices, the navigation links are hidden by default. 
- Click the hamburger menu icon to toggle the visibility of the navigation links.
- The icon is styled in white for better visibility against the background.

## Customization
- You can customize the styles in `style.css` to change the appearance of the hamburger menu and navigation links.
- Modify `script.js` to change the functionality of the hamburger menu if needed.
